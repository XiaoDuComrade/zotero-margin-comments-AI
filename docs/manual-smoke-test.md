# Zotero 9.0.6 人工验收

1. 使用单独的 Zotero 测试配置文件安装 `margin-comments-ai-0.10.3.xpi`。
2. 打开包含高亮评论、下划线评论和独立便签的 PDF。
3. 确认工具栏出现“页边批注”按钮；页面左半区批注的卡片位于左边，右半区批注的卡片位于右边，引线从批注上边缘引出。
4. 在同一侧创建足以超过页面高度的评论，确认页面底部出现“还有 N 条”，且卡片不延伸到下一页。
5. 点击“还有 N 条”，确认只有当前侧边栏展开滚动；滚动时可见卡片的引线同步移动，滚出视野的卡片不显示引线；点击“收起评论”恢复折叠。
6. 确认卡片顶部不再显示“高亮解释/文本批注”和页码，只显示评论内容。
7. 鼠标悬停卡片，确认卡片轻微向外放大并出现浮起阴影，同时对应引线和 Zotero 原批注同步加重；移开鼠标后恢复。
8. 点击卡片，确认原批注被 Zotero 选中并定位；点击原批注，确认对应卡片边框高亮。
9. 在卡片输入中文，等待 700 ms；关闭再打开 PDF，确认内容仍在 Zotero 原批注中。
10. 确认卡片中没有“保存”按钮，并测试 `Ctrl + Enter` 立即保存、`Esc` 取消以及失焦保存。
11. 为评论输入四行以上内容，失焦后确认只预览三行且末尾有省略号；点击预览后确认完整编辑框展开。
12. 将 PDF 缩放到 80% 以下，确认卡片保持固定字号并折叠为一行；恢复到 80% 以上后确认恢复三行预览。
13. 对没有评论的高亮右键，选择“在页边显示/编辑评论”，输入内容并保存。
14. 新建一个 Zotero 独立便签，确认空卡片随即出现并可写详细内容。
15. 连续快速放大和缩小 PDF，确认卡片与引线逐帧跟随页面，不短暂串位、不消失、不闪烁；再测试旋转、窗口调整和翻页，确认引线仍指向正确位置。
16. 点击工具栏按钮隐藏和重新显示卡片；重启 Zotero 后确认开关状态保留。
17. 切换深色模式，确认卡片和文本框可读。
18. 测试只读组库批注，确认卡片显示“只读”且不可修改。
19. 禁用并重新启用插件，确认工具栏按钮、覆盖层和事件没有重复。
20. 分别打开“有旁注”和“无旁注”的 PDF，连续放大、缩小，确认两种情况的缩放中心都始终位于页面中线。
21. 在 Zotero 原生批注筛选中按颜色、标签或搜索词过滤，确认被过滤的批注及对应旁注同时隐藏；清除筛选后两者同时恢复。
22. 打开 Zotero“编辑 → 设置 → 页边批注”，依次取消高亮、下划线、便签、文字批注和图片/区域的勾选，确认对应类型立即隐藏；重新勾选后立即恢复。关闭并重新打开 Zotero，确认各类型的选择被保留，且 Reader 工具栏中不再出现设置齿轮。
23. 在“编辑 → 设置 → 页边批注 → 阅读器外观”中开启“缩小便签图标”，确认说明文字包含强版本依赖提示；所有已打开 PDF 的原生便签图标应立即从 24 像素缩小到约 14 像素，只能在缩小后的图标范围内选中和拖动，引线圆点落在图标上边缘；缩放、旋转后仍保持对齐。关闭后应立即恢复原始图标和点选范围，重启 Zotero 后选择仍被保留。
24. 在“编辑 → 设置 → 页边批注 → AI 学术标注”中启用功能，选择自动检测、Responses 或 Chat Completions，填写 API 地址、API Key 和模型；展开“查看默认系统提示词”，确认完整提示词可选择复制，且补充要求输入框保持独立可编辑；点击“测试连接”，确认成功状态会标明实际协议，且 API Key 不出现在错误文字中。
25. 开启 AI 后打开 PDF，确认工具栏出现紫色星光按钮；不点击时观察网络，确认插件不会自动上传。点击后取消第一次确认，确认没有网络请求和新批注。
26. 再次点击并确认，Reader 右上角应依次显示读取文字层、已连接模型、模型正在分析论文、正在接收标注结果、匹配原文和写入批注状态；等待状态应持续更新秒数，按钮有呼吸动画且再次点击可取消。完成后检查写入前摘要：模型建议数、成功定位数和跳过数应清楚显示；取消时不得创建批注。
27. 确认写入后，检查所有新批注均为 Zotero 高亮、使用设置中的同一颜色、评论为专业中文，并带有“AI 学术标注”标签；逐条抽查高亮原文与评论引用对象一致。
28. 使用 Zotero 原生颜色筛选隐藏该专属颜色，再恢复全部批注；确认 AI 高亮及其页边评论同步隐藏和恢复。再按“AI 学术标注”标签筛选一次。
29. 使用含重复句、双栏排版和印刷页码与 PDF 页码不一致的论文测试，确认插件按物理 PDF 页码定位，并且不能可靠匹配的建议不会写入错误位置。
30. 使用纯扫描且没有文字层的 PDF 测试，确认模型分析后提示无法取得文字层，不创建伪造坐标批注。使用接近或超过 50 MB 的 PDF 测试文件大小错误。
31. 使用约 100 页且末尾包含 References 的长论文测试 Chat Completions：确认进度显示“第 N/M 段”，M 不超过 8；最终批注分布于不同批次；参考文献标题之后的纯文献页不产生候选。如果服务商中途关闭响应流，错误应指出失败批次，不应只显示 `Error in input stream`。
32. 用会返回 `reasoning_content` 的模型重复长论文测试，确认长分块请求的 `max_tokens` 会随分块文字量增加；单批返回 `{"annotations":[]}` 时后续批次仍继续。模拟 `finish_reason: "length"`，确认提示明确区分“尚未生成 JSON”和“JSON 被截断”。
33. 在设置页最下方单独开启“用网页对话”，即使关闭“启用 AI 学术标注”，Reader 星光按钮也应显示；确认原 API 地址、Key 和模型设置没有被清空。
34. 点击星光按钮并确认，在任意文本输入框按 `Ctrl+V`：确认剪贴板中只有以 `ZMC_WEB_CHAT_REQUEST_V1` 开头的纯文本提示词，没有 PDF 或临时 TXT。自行向网页 AI 上传当前 PDF，再粘贴该提示词并发送。
35. 发送后复制模型完整回复；确认 Zotero 的等待提示自动变为匹配原文及写入预览。复制普通文字时应显示已经检测到剪贴板变化但尚未识别完整结果；其他任务编号或旧回复不得触发；再次点击星光按钮应立即取消监听。
36. 分别从纯文本编辑器和提供富文本复制的网页复制回复，确认 `text/plain`、Unicode 或 HTML 剪贴板格式均可识别；再测试带 `ZMC_WEB_CHAT_RESULT_V1` 的标准回复，以及省略标记但保留正确 `request_id` 的 JSON，两者都应被识别。在预览中取消时不得创建批注；确认后检查统一颜色、标签、页码、原文与评论。模拟错误任务编号、不完整 JSON、剪贴板桥连续读取失败和超过 30 分钟，确认均不误写批注并给出可理解的结果。
37. 缩窄和放宽 Reader 窗口，确认页边批注按钮与紫色星光按钮始终位于同一横排，且左右顺序不变。
